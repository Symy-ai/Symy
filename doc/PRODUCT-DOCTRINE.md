# 产品铁律（owner 定案 2026-09-06）

## 面子与里子

**绿色环保是面子，省钱是里子。**

用户必须同时拿到两者：
- **面子**：可晒的绿色荣誉（拦截是勋章不是说教；"我在做对的事"的身份故事）
- **里子**：真实省下的钱（每次拦截、每次绿色替代、每次复用建议，都要让用户看到省了多少）

只给面子 = 虚荣工程；只给里子 = 羁绊框架（省钱=羞耻，用户不愿传播）。
两者兼得 = 用户得到实际利益 + 转发时体面 → 传播引擎的自养循环。

## 执行标准

每个新功能过审前自问：
1. 这个功能的面子是什么？（可晒/可认同/荣誉感）
2. 这个功能的里子是什么？（真实省下的金额或资源）
3. 两者都可见吗？缺一个就补齐再上。

## 其他不变约束
- 荣誉框架非羞耻框架（绝不暗示用户穷）
- 禁止编造碳足迹具体数值（定性 only，有真实数据源再说）
- 零 DDL；Shopping 仓库禁改；i18n 双语；无新 npm 依赖
