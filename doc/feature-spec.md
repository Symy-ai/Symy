## 1. Chat 认知揭示系统（第二层·认知层）

### 1.1 功能概述

Chat 页面是 Symy AI 的主页面（Tab 1），用户在此与 AI 伴侣 Symbio 进行实时对话。基于 CBT（认知行为疗法）框架，帮助用户反思消费动机、做出理性决策。在清华大学心理学团队指导下，将"自动思维识别→认知歪曲检验→替代思维生成"的CBT路径嵌入AI决策流。

### 1.3 CBT认知行为疗法路径

```
用户表达消费意图
    │
    ▼
自动思维识别
  AI识别用户的自动思维（如"限时3件"=稀缺性FOMO、"我值得犒劳自己"=情感补偿）
    │
    ▼
认知歪曲检验
  AI帮助用户检验思维是否存在认知歪曲：
  ├─ 灾难化："不买就没了"→ 检验：真的买不到吗？
  ├─ 全或无："我值得犒劳自己"→ 检验：犒劳只有买这一种方式吗？
  ├─ 情感推理："我就是想买"→ 检验：想=需要吗？
  └─ 贴标签："我控制不住自己"→ 检验：过去有控制住的时候吗？
    │
    ▼
替代思维生成
  AI帮助用户生成更理性的替代思维，并提供行动建议
```

### 1.4 诱导拦截模型

```
诱导消费触发
    │
    ▼
情绪触发识别
  ├─ 识别情绪类型（FOMO/情感补偿/社交压力/习惯性）
  └─ 记录触发场景（深夜/工作疲惫/社交比较）
    │
    ▼
真实需求评估
  ├─ 这笔消费解决什么问题？
  ├─ 有没有替代方案？
  └─ 过去类似消费的后悔率？
    │
    ▼
三档干预
  ├─ 值得买 → 绿灯放行，买得理直气壮
  ├─ 可延后 → 黄灯暂停，24h冷静期后再决定
  └─ 谨慎购买 → 红灯拦截，发起理性闯关
```

## 3. 未来盲盒 Future Gacha（第三层·视角层）

### 3.1 功能概述

未来盲盒是对付诱导消费的最深层武器。诱导消费的根源不是意志力弱，是商家用算法劫持了你的注意力与决策，加上大脑的**时间贴现偏误**（present bias）：$100现在的快乐 > $1,000以后的快乐，因为"以后"太模糊。未来盲盒把"以后"变成你正在经历的人生→贴现偏误自动减弱。

AI生成的个人化未来叙事：不是数据预测，是**沉浸式体验**——你在"经历"那个未来，而不只是"看到"一个数字。

## 4. 理性闯关 Challenge（第四层·行为层）

### 4.1 核心理念 — 无论输赢都爽

前三层创造了"不想买"的意愿，Challenge给了"不买"的出口。

**消费决策四层框架**：欲望触发→决策判断→选择比较→执行下单。Symy占据"决策判断"层——控制"该不该买"这一层→控制流量入口。其他所有玩家都在第0层（让你想买：小红书/TikTok/Instagram）或第2-3层（帮你买：Amazon/Google/PayPal），没有人站在消费者这边帮"想"。为什么大厂做不了？Google（广告收入）、Amazon（商品收入）、TikTok（电商GMV）、PayPal（交易手续费）——营收全部与消费量正相关。反诱导消费=反噬其营收（创新者窘境）。只有Symy没有利益冲突。

凌晨两点，你盯着那双Nike Air Max，手指已经搭在"Place Order"上。这时候Symy跳出来：**"Challenge me."** 你输入物品和价格，一场模拟对抗随即开始。

- **赢了？买！** 说服AI=理性决策通过→买得理直气壮。这是真正的需求，不是被诱导的欲望——刚通过严格审查。
- **输了？也爽！** 说服不了AI=诱导被识破→钱涌入梦想基金。冰岛旅行37%→41%，信用卡还款少一截，Symy生命力暴涨。每一分钱都有去处。

**传统App=剥夺感，Symy=获得感。赢了→钱换实物（理性消费），输了→钱进梦想基金（延迟满足）。**

### 5.4 诱导评分算法

