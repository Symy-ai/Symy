## 召回程序

任一文档召回须按以下程序：

1. **触发条件确认**：Foundation 理事会确认召回触发条件已满足（月活 / 独立审查院设立 / 融资启动 等）
2. **召回决议**：Foundation 理事会 2/3 通过
3. **物理移回**：将归档文档从 `_archive/pre-startup/` 移回主目录
4. **导航更新**：更新 `README.md` 导航表 + `_archive/pre-startup/README.md` 归档清单
5. **公告**：在 symylab.org/recalls 公告召回原因 + 召回日期 + 生效条款
6. **worklog 记录**：在 `/home/z/my-project/worklog.md` 追加召回记录
